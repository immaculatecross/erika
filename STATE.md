**v0.6 CLOSED 2026-07-25 — and its D-17 cold-start gate FAILED (RUN-006, RETRO-004).** Both halves are true and the tension is the finding. v0.6 was the **best-tested version of this project and the least usable**: 1012 tests at close, four independent review rounds on the final milestone — and a new user with no API key **could not get a single recording through the pipeline**, while the app's own remedy was a loop. Nothing 500'd, nothing blanked, every empty state was well-written; the product lens's words were *"v0.6 fails cold start not because it is broken, but because it is inert."* Four criticals were found by **driving the built app on a fresh keyless DB**, all invisible to 967 passing tests, all fixed before close. **(1)** The worker exited 1 without `OPENAI_API_KEY`, so nothing was ever ingested, and `npm run worker` — the app's own instruction — printed two lines and quit; speech extraction makes **zero** model calls, so the gate was blocking a stage that runs much later. The worker now drains the ingest queue keylessly and refuses an analysis job terminally *per job*, staying up (#63). **(2)** A careless placement returned **"Placed around C2." with no caveat** while the same result failed A1 and A2, seeded 238 rules, and **re-taking placement honestly did not repair it** — only deleting the DB recovered. `level` is now the top of the **contiguous** run from A1, `calibrated` can never read true above the false-alarm threshold, and migration **v27** `placement_runs` makes supersession an INSERT-only read-path rule that never touches the v14 append-only triggers (#63). **(3)** A database that ever booted `feat/pronunciation-studio` was **permanently unbootable**: v24 really *was* applied there, the renumber to v26 shipped with no repair step, and `runMigrations` threw on every boot forever. `lib/migrations/reconcile.ts` now completes the v26 end state and rewrites the stale ledger row; three comments asserting v24 "never shipped" are corrected (#63). **(4)** Placement's false-alarm threshold gated **presentation but not seeding** — a careless run wrote 39 recognition rows while the screen said the daily plan was unchanged — and the first repair applied its own reasoning to only one of the three branches that record a run, so an honest learner who retook the check unevenly had all 173 grammar rules silently erased under *"nothing else has changed"*.
